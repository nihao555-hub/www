# Test Plan — 21st MCP fix + generate UI changes (prod)

Target: https://web-production-b4010f.up.railway.app/generate (Railway prod, branch `devin/1782543904-template-mode`)

## What changed (user-visible)
1. MCP calls (`21st_magic_component_inspiration`) now retry w/ longer timeout → fewer "MCP 调用失败 / 0 个结果".
2. Tool cards show the **full** component source (was sliced at 1400 chars).
3. Template mode: card grid removed; mode toggle sits **below** the input; defaults to AI auto-match; manual picker is a collapsed "高级" link.
4. Left workflow rail widened (was `lg:w-1/5` 20% → `lg:w-[40%]`).
5. Right panel: top **界面 / 代码** switcher + **下载代码** button; code view fetches `/next/sites/<slug>/code`.
6. Build-time loading animation is richer (assembling-site skeleton, phase icons, rotating tips).

## Primary flow — creative-mode generation (proves MCP + most UI)
Pre: open `/generate`. Default mode = 自由创意.

1. Upload a product image (required for creative), type a brief, press send.
   - PASS: workspace layout appears; left rail is clearly wider than a thin 20% strip (~40% of width).
2. Watch the **inspire** step ("通过 21st.dev MCP 搜索组件与图标").
   - PASS: at least one `component_inspiration` tool card reaches status **Completed** with a component name + match score + a code block. NOT every card showing "MCP 调用失败 / 0 个结果".
   - FAIL if all MCP cards are red errors / 0 结果.
3. Expand a Completed tool card's code block.
   - PASS: code is long/complete and scrolls (not cut off mid-statement at ~1400 chars). A broken impl would show a short truncated snippet ending mid-token.
4. While generating, observe the right panel loading state.
   - PASS: shows the animated mock-site skeleton + pulsing phase icons + rotating Chinese tips (text changes over time), not a single static spinner.
5. When done, the site renders in the right preview iframe.
   - PASS: a real landing page renders (no white screen / error).
6. Top of right panel: click **代码**.
   - PASS: view switches to dark code panel showing assembled `.tsx` source (banner `// === <site> — generated by AI Site Generator ===`, hero JSX, section code, spec JSON). Click **界面** → switches back to iframe.
7. Click **下载代码**.
   - PASS: a `<slug>.tsx` file downloads.

## Secondary — template mode UI (no full generation needed)
